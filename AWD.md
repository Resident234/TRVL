## Идеи и задачи (сырой бэклог)

### Активные идеи

1. Добавить фото в шапцу поста если нет фото в посте (foto заглушка) — фото города (страны) делаем через unspash api или google api фото города
2. Кнопка для отправки статьи в канал если посты заканчиваются (получение постов из Telegram по интервалу дат + отправка в канал)
3. В настройках канала добавить поле — ссылка на пост в канале с правилами
4. Проверить вёрстку на мобайлах
5. Сделать светлую и тёмную тему для формы и предпросмотра
6. Сделать логотип для канала в настройках
7. Добавить emoji-пикер для кнопки ссылки
8. Добавить emoji-пикер для заголовка
9. У кнопки ссылки добавить emoji
10. У названия части добавить emoji
11. Настройки: сэкономить место, сделать компактнее, например схлопываемые секции
12. Добавить обрезку фото под аватарку/обложку канала (circle/crop)
13. История изменений картинки канала
14. История изменений описания канала (на отдельной странице)
15. Уведомления в Telegram при ошибках парсера
16. Парсер: пропуск неизменённых элементов, обнаружение обновлений, дописывание новых
17. Парсер: текст для описаний канала брать из постов
18. Парсер постов: получать emoji смайлы форума и конвертировать в настоящие emoji
19. Парсер: автоматическое определение страны по заголовку и простановка emoji флага
20. Парсер: автоматическое определение города и простановка герба
21. Парсер: определение места действия и вывод названия через Google API / 2GIS API
20. Парсер тем: тематика постов/топиков, опираться на разделы
21. Стиль предпросмотра — сделать аутентичным посту в Telegram
22. Алгоритм расположения фото в предпросмотре — угадать алгоритм Telegram (2-10 фото)
23. Статусы и другие элементы каналов — найти образцы
24. Визуальный конструктор для кнопок поста
25. Drag-and-drop элементов на блоке предпросмотра
26. Форматирование и emoji в тексте ссылки-кнопки — настраиваемо
27. Выбор и поиск emoji в отдельное поле формы — настраиваемо
28. Развитие emoji-функционала — максимально приблизить к интерфейсу Telegram
29. Выводить техническую информацию об изображениях (разрешение)
30. Настройка порядка расположения фото в блоке предпросмотра и на форме
31. Блок предпросмотра — сделать по размеру в точности как в Telegram
32. Кастомные реакции https://prnt.sc/cMQJ90jA45QX
33. Логотип — пока используем тот который есть, подберём со временем новый из имеющихся изображений
34. У изображений в форме поле возле превьюшек — кнопка добавления этого изображения в качестве картинки канала. На отдельной странице — история изменений картинок канала. А также настройка расположения логотипа (размер в %, позиция по вертикали/горизонтали)
35. У описания канала должна быть история изменений (проверить реализацию), продублировать на отдельной странице
36. Выделение текста / кнопки возле блока формы (если разбиение на части неактивно) и возле каждой части — две кнопки: отправка текста в описание канала, отправка с предварительным редактированием в модальном окне
37. История изменений статьи или частей статьи — над полем текста, ссылка на отдельную страницу (после автосохранения формы)
38. Функционал истории изменений текста на форме

### Отложено

- Статусы и другие элементы каналов — найти образцы
- Визуальный конструктор для кнопок для поста
- На блоке предпросмотра текста — возможность перетаскивать элементы
- Возможность форматировать и добавлять emoji в текст ссылки-кнопки — управляется настройками
- Выбор и поиск emoji положить в отдельное поле формы — управляется настройками
- С emoji развить функционал, максимально приблизив к функционалу в интерфейсе Telegram
- Выводить техническую информацию об изображениях, например разрешение
- Настройка порядка расположения фото в блоке предпросмотра и на форме
- Блок предпросмотра сделать по размеру в точности как размер в Telegram
- Кастомные реакции https://prnt.sc/cMQJ90jA45QX
- Логотип — пока используем тот который есть, подберём со временем новый из имеющихся изображений
- У изображений в форме поле возле превьюшек кнопка добавления этого изображения в качестве картинки канала. На отдельной странице нужно история изменений картинок канала. А также настройка расположение логотипа на этой картинке с опциями размер относительно размеры картинки в процентах, а также расположение по вертикальной горизонтальной оси
- У описание канала должна быть история изменений, надо перепроверить что это уже реализована, Но продублировать это ещё на отдельной странице

- История изменений статьи или частей статьи вводить над полем текста, а также сделать ссылку на отдельную страницу — Это после реализации автосохранения формы
- Функционал истории изменений текста на форме
