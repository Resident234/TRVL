# Лекция 1: Показатели скорости OpenAI-совместимого proxy

## Быстрый старт
1. Настроить локальный proxy (уже настроен)
2. Запустить скрипт:
   ```bash
   php backend/llm/speed-reader.php
   ```
3. Скрипт автоматически:
   - Получает список моделей
   - Для каждой модели запускает запрос
   - Измеряет время ответа в миллисекундах и секундах
   - Выводит сортированный отчет

## Интерфейс
```bash
php backend/llm/speed-reader.php
# ИЛИ
php backend/llm/speed-reader.php --model=gpt-3.5-turbo
```

## Результат
Пример вывода:
```
Модель: gpt-3.5-turbo
Время ответа: 45 мс (0.045 с)
Ошибок: 0

Модель: gpt-4-turbo
Время ответа: 820 мс (0.820 с)
Ошибок: 0
```

## Итог
Таймаут для стилизации = `максимальное время ответа + буфер (0.5-1.0 с)`
Пример: для gpt-3.5-turbo → 1.5 с; для gpt-4-turbo → 2.5 с.

## Интеграция
Скрипт генерирует JSON:
```json
[
    {
        "model": "gpt-3.5-turbo",
        "elapsed_ms": 45.2,
        "text": "..."
    }
]
```

Этот JSON можно использовать второстепенно для подгрузки в конфигурацию приложения.
