# Шаблон адреса темы для парсинга

## Формат

```
https://forum.awd.ru/viewtopic.php?t={id}
```

## Параметры

| Параметр | Назначение | Диапазон |
|---|---|---|
| `t` | Идентификатор темы форума | Диапазон задаётся отдельно для каждой строки `parser_config` через `t_from` / `t_to`; начальный диапазон конфигурации `awd_forum_topics` — `0–500000` |

`{id}` подставляется целым числом без ведущих нулей. Значения в таблице — начальные настройки, а не жёсткий предел парсера: диапазон можно изменить на странице `/parser-settings`.

## Примеры

- `https://forum.awd.ru/viewtopic.php?t=441019` — тема «Малоярославец. Май 2026. Город белый, город голубой»
- `https://forum.awd.ru/viewtopic.php?t=1` — несуществующая тема, отвечает HTTP 404

## Хранение

- База шаблона без подстановки: `parser_config.base_url` (например, `https://forum.awd.ru/viewtopic.php?t=`); сервис добавляет к ней текущий id
- Готовая ссылка сохраняется в `topic.source_url`; для сканера тем она заново строится из `base_url` и id при каждом проходе
- Таблица `parser_config` также содержит отдельные строки диапазонов для постов, галерейных альбомов и профилей участников; URL этих сущностей описаны в [PARSER.md](PARSER.md)

## Ответы сервера

| Ответ | Обработка |
|---|---|
| HTTP 200 | Парсинг и upsert в БД |
| HTTP 404 | Считается `not_found`, пропуск без ошибки |
| HTTP 429 / 5xx | Повторные попытки с нарастающей задержкой, затем `failed` |
| 200 без темы («вы должны быть авторизованы») | Считается `login_required`, пропуск без ошибки |
