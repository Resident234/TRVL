# Шаблоны адресов для парсинга форума awd.ru

Все URL относятся к `forum.awd.ru` (phpBB) и подставляются в `parser_config` через поля `base_url`; диапазоны значений параметров задаются для каждой сущности отдельно (`t_from`/`t_to` и аналоги). Начальные диапазоны — `0–500000`, но это начальные настройки, а не жёсткий предел: диапазоны и `login_url` редактируются на странице `/parser-settings`.

## Темы (awd_forum_topics)

```
https://forum.awd.ru/viewtopic.php?t={id}
```

| Параметр | Назначение | Диапазон |
|---|---|---|
| `t` | Идентификатор темы | Задаётся в `parser_config` через `t_from` / `t_to`; начальный диапазон `0–500000` |

Примеры:
- `https://forum.awd.ru/viewtopic.php?t=441019` — тема «Малоярославец. Май 2026. Город белый, город голубой»
- `https://forum.awd.ru/viewtopic.php?t=1` — несуществующая тема, HTTP 404

## Посты тем (awd_forum_posts)

```
https://forum.awd.ru/viewtopic.php?t={topic_id}&start={start}
```

| Параметр | Назначение | Диапазон |
|---|---|---|
| `t` | Идентификатор темы | Те же строки `parser_config`, что и для тем; диапазон отсечения применяется к топикам |
| `start` | Сдвиг пагинации | 0, 50, 100, … (50 постов на страницу); мержится до `max_pages` (по умолчанию 10000) |
| `p` | Идентификатор поста | Извлекается из каждого поста на странице, не перебирается |

## Альбомы галереи (awd_gallery_albums)

```
https://forum.awd.ru/gallery/album.php?album_id={id}
```

| Параметр | Назначение | Диапазон |
|---|---|---|
| `album_id` | Идентификатор альбома | `parser_config` для галереи: `t_from`/`t_to`, начальный `0–500000` |

### Изображения альбомов

```
https://forum.awd.ru/gallery/image_page.php?album_id={album_id}&image_id={id}
```

| Параметр | Назначение | Диапазон |
|---|---|---|
| `image_id` | Идентификатор изображения | Извлекается из страницы альбома (пагинация 100 на страницу, `start=N`) |
| `album_id` | Привязка альбома | Из ссылки на странице изображения |

## Профили участников (awd_forum_members)

```
https://forum.awd.ru/memberlist.php?mode=viewprofile&u={id}
```

| Параметр | Назначение | Диапазон |
|---|---|---|
| `u` | Идентификатор пользователя | `parser_config` для профилей: `t_from`/`t_to`, начальный `0–500000` |

Вкладка статистики пользователя: `?mode=viewprofile&u={id}&page=7`.

## Ответы сервера

| Ответ | Обработка |
|---|---|
| HTTP 200 | Парсинг и upsert в БД |
| HTTP 404 | `not_found`, пропуск без ошибки |
| 429 / 5xx | Повторные попытки с нарастающей задержкой, затем `failed` |
| 200 без сущности («вы должны быть авторизованы») | `login_required`, пропуск без ошибки, сохраняется заглушка |
